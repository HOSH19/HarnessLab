# Reading list

1. [Graph Engineering in the Era of LLM Agents (arxiv survey)](https://arxiv.org/html/2608.21156v2) — system intelligence via task graphs, agent coordination, runtime state.
2. [3 Years of Graph Engineering with LangGraph (LangChain)](https://www.langchain.com/blog/3-years-of-graph-engineering-with-langgraph) — graphs constrain paths; loops are cyclic graphs; production needs cycles and `Send`.
3. [What is Graph Engineering? (DataCamp)](https://www.datacamp.com/tutorial/graph-engineering-guide) — nodes, edges, shared state; hands-on LangGraph orchestration.
4. [Graph Engineering: Practical Guide (Ryzo)](https://www.ryzo.nl/resources/blog/graph-engineering) — stack framing; task graph vs knowledge graph; when splitting nodes pays off.
5. [Andrew Ng, Loops & Graphs (TrueFoundry)](https://www.truefoundry.com/blog/andrew-ng-loop-graph-engineering-production) — graph owns routing; loop owns local act/observe; not knowledge graphs.
6. [LangGraph Graph API](https://docs.langchain.com/oss/python/langgraph/graph-api) — primary-source API for state, nodes, edges, `Send`, `Command`.
7. [Harness, loop and graph engineering (TensorFolk)](https://tensorfolk.com/articles/harness-loop-graph-engineering/) — short definitions of all three layers.
